# C / C++ Programming Labs

Coursework and practice programs in C and C++: lab assignments, OOP exercises (classes, inheritance) and early Python scripts.

## Contents

| Path | Description |
|------|-------------|
| `codeblocks/LAB 1`, `labs 2`, `labs 4`, `Assignment 4`, `inputs an outputs`, `trial` | C lab assignments (Code::Blocks projects) |
| `codeblocks/python journey/` | Introductory Python scripts |
| `emp.cpp`, `work.cpp`, `wow.cpp` | C++ class exercises (employee records) |
| `inherin.cpp` | C++ inheritance example |
| `cal.cpp`, `hm.cpp`, `task.cpp` | Assorted C++ practice programs |

## Build

```bash
gcc main.c -o app        # C programs
g++ file.cpp -o app      # C++ programs
```

You can also open any `.cbp` file in Code::Blocks.
