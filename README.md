# C / C++ Programming Labs

Coursework and practice programs in C and C++: lab assignments, OOP exercises (classes, inheritance) and early Python scripts.

## Contents

| Path | Description |
|------|-------------|
| `LAB 1/` | First C program: `puts`/`printf` and variables |
| `inputs an outputs/` | `scanf` input: BMI calculator |
| `Lab 5 Assignment/` | Area of 6 composite shapes and 6 shaded regions, using `rectangle()`, `triangle()` and `circle()` functions |
| `lab 5 assignment 2/` | Shaded-region areas (second part of Lab 5) |
| `lab 6 Assignment/` | **ABC Bank ATM**: PIN login with lockout, balance, withdraw, deposit, transfer (demo PIN `1234`) |
| `LABS 7Assignment(4109924)/` | Student marks: mean, bubble sort, grade table and **CWA** calculation |
| `ARRAY/` | Code::Blocks starter project |
| `codeblocks/LAB 1`, `labs 2`, `labs 4`, `Assignment 4`, `inputs an outputs`, `trial` | C lab assignments (Code::Blocks projects) |
| `codeblocks/python journey/` | Introductory Python scripts |
| `emp.cpp`, `work.cpp`, `wow.cpp` | C++ class exercises (employee records) |
| `inherin.cpp` | C++ inheritance example |
| `cal.cpp`, `hm.cpp`, `task.cpp` | Assorted C++ practice programs |

## Recovered sources

The `main.c` files in `ARRAY/`, `LAB 1/`, `inputs an outputs/`, `Lab 5 Assignment/`, `lab 5 assignment 2/`, `lab 6 Assignment/` and `LABS 7Assignment(4109924)/` were recovered from the compiled Debug builds after the original source files were lost. Each one was rebuilt and checked to give **identical output** to its original executable on the same input.

## Build

```bash
gcc main.c -o app        # C programs
g++ file.cpp -o app      # C++ programs
```

You can also open any `.cbp` file in Code::Blocks.
